--- What the Experiment Reveals ---

1. Baseline per-pair time *drops* with deeper nesting (78.5 → 23.2 ns).
   Three shared locks across 40 threads is a heavily contended workload —
   most acquires block. Forty locks in a fixed order spreads contention
   across the chain, so each individual acquire is uncontended more often
   and the per-pair cost approaches the uncontended pthread fast path.

2. Lockdep overhead ratio rises with depth for the global backend
   (2.15× → 2.79×) but actually *falls* for the rb backend (2.26× → 2.32×,
   essentially flat). The rb backend's amortization wins as soon as the
   nested acquire path does enough graph work to exceed the cost of an
   enqueue-and-signal hand-off.

3. The two backends cross over between depth 3 and depth 40. At depth 3,
   global beats rb by ~5% — the per-acquire graph work is small enough
   that the hot-path simplicity of synchronous DFS wins against the rb
   queue overhead. At depth 40, rb beats global by 17% — the worker
   thread absorbs the O(N²) per-iteration edge maintenance off the
   application threads.

4. Per-pair lockdep cost *decreases* with depth for both backends
   (global 90.5 → 41.5 ns, rb 98.9 → 30.7 ns). Because each iteration
   contributes 40 acquire events to amortize the same constant per-iter
   bookkeeping, the marginal cost per pair falls. The rb backend
   amortizes more aggressively, consistent with point 2.

5. Predecessor summaries are doing real work in both backends. Once a
   thread has executed one full A→B→…→Z chain, every subsequent
   iteration finds the dependency edges already present and skips both
   the matrix update and the DFS. Without this, deep-nest global mode
   would scale O(N²) per iteration and the deep/shallow per-pair ratio
   for global would be much higher than the observed ~0.46× (vs 0.30×
   for baseline).

6. Held-stack ceiling not hit: 40 of 64 LOCKDEP_MAX_HELD_LOCK_SLOTS used.
   Pushing N to 64 would make this a true stress test of the held-stack
   data structure; at N=40 the held stack stays comfortably below the
   limit and the experiment reflects steady-state graph cost rather than
   structural overflow behavior.
